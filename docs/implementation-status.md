## 確認したこと

- Django自動テスト：67件成功。認証・CSRF・チーム分離、権限変更、料金条件、未知の商材・プラン、相違、質問修正・取消、回答順序逆転、時間切れ、資料の版更新・削除、外部AIアダプターに加え、WAV検証・Whisperの未準備・プロセス再利用・混雑・時間切れ後の復帰・外部通信しない経路・音声APIの重複防止・商談終了後の結果破棄を含む。単体テストではモデル処理をモック化し、実モデルは下記で別に確認。
- React：Vitest 15件成功（質問状態5件、音声取得のブラウザAPIモック10件）。TypeScriptチェックとViteビルド成功。
- DBマイグレーションの未作成差分なし。
- ローカルHTTP接続：8件の質問を同時に回答処理し、すべて`ready`として保存できた。1回の機能確認であり、部署全体の性能保証ではない。
- ブラウザ：検証用ログイン、商談作成、質問手入力・修正後の再検索、料金条件・原文表示、原文から戻った時のフォーカス復帰、連続質問の新着表示と選択保持、根拠なし・資料間の相違、対応結果・絞り込み、検索失敗からの再試行、架空Markdownのアップロードと抽出本文を確認。
- 表示更新の一時停止中は画面上の質問7件を保持し、裏側で処理した5件を再開時にまとめて反映。選択中の質問も保持。
- 商談小型表示は420px／320 CSS pxで横はみ出しなし。320pxでルート文字サイズを200%（32px）にした状態でも本文・操作・根拠ダイアログの横はみ出しなし。Escapeによるダイアログ終了と元の引用ボタンへのフォーカス復帰を確認。画面全体のWCAG適合・スクリーンリーダーによる確認は未実施。

## 次の検証段階

1. 架空資料を用い、答えあり30問・答えなし10問・非質問20発言と境界例を調整用／最終評価用に分ける。商材を理解する人による正誤・必要条件・引用の評価を行う。
2. ローカルWhisperの雑音・長文・区切りを含む日本語精度と遅延を検証する。回答生成の外部AIを使う場合は別途サービス・利用条件を確認して架空データで実接続する。実商談データへの許可とは分ける。
3. Windows／Mac、オンライン6組み合わせと対面2組み合わせで相手・同席者の音声取得を試す。ブラウザで不足する経路はネイティブ補助アプリ等を検討する。
4. 部署での同時利用・通信切断・長時間動作・アクセシビリティを評価する。SQLite・開発サーバーから運用構成への移行を検討する。
5. 社内の実データ利用・保持・権限条件を確定し、実商談で通常の資料検索と比較する。

`elapsed_ms`はサーバー内の検索・回答処理時間のみ。発話終了からの文字起こし・通信・画面表示を含む中央値5秒／p95 8秒の達成値として扱わない。10秒の遅延表示・30秒のタイムアウトは初期の仮設定。

初期設定は`AI_MODE=local`、`TRANSCRIPTION_MODE=whisper`、`WHISPER_MODEL=small`、`ALLOW_REAL_DATA=false`。模擬発言はテキストの投入であり音声認識のデモとは表示しない。外部AI・実機音声・Windows・実商談を検証済みとは扱わない。

## ローカルWhisperの実測

2026-09-29、Apple M1／macOS 26.6.2／Python 3.11／openai-whisper 20250625／PyTorch 2.14.0、CPU・4スレッド・日本語・fp32。macOSのKyoko音声で架空の質問をWAV化し、認証・CSRF付きの実HTTP音声API → Whisper → 質問検知 → 回答APIへ送った。外部の音声API・LLMは使っていない。ブラウザのマイク・画面共有を通す試験ではない。1利用者・順次実行。

| 音声（長さ） | smallの認識結果 | 音声API送信から回答API完了まで | 回答の状態 |
| --- | --- | --- | --- |
| 料金はいくらですか（1.59秒、16kHz）・初回 | 料金はいくらですか | 5.61秒（子プロセス起動・モデル読み込みを含む） | 根拠あり・引用1件 |
| 同じ料金の質問・2回目 | 料金はいくらですか | 1.12秒 | 根拠あり・引用1件 |
| 導入するまでどのくらいかかりますか（2.79秒、48kHz） | 導入するまでどのくらいかかりますか | 1.19秒 | 根拠あり・引用1件 |
| データの保存地域はどこですか（2.44秒、16kHz） | データの保存地域はどこですか | 1.12秒 | 根拠が見つからない |
| デジタル無音（1秒） | 発言・質問を作成しない | 0.01秒未満 | transcript:null |

baseでは同じ料金音声を「両筋はいくらですか」、導入音声を「どう入するまでどのくらいかかりますか?」と誤認識し、後者は検索の根拠が見つからなかった。smallではこの2例が改善したため、初期値をsmallへ変更した。3種類の短い合成音声による調整例であり、独立した最終評価・認識精度の保証ではない。

ブラウザで、実Whisperの認識結果から作られた料金の質問・回答候補・引用、および音声取り込み前のローカル処理の案内を確認。マイクはこの作業で起動していない。検証素材と測定JSONは`.local/whisper-eval/`（Git対象外）に保持し、アプリの音声取り込み経路はWAVを保存しない。

測定値には発話を区切る0.8秒の無音待機・音声収集・画面描画を含まない。実際の発話終了から回答表示までのp95目標を満たしたとは判断しない。起動直後の追加時間も評価対象とする。モデルはプロセスごとに1つで、認識を順次処理しロック待ちは最大3秒。部署規模の同時利用は未評価。ブラウザの最大6秒区切りで質問が分断される可能性、環境音からの誤認識、CPU・メモリ差による遅延が残る。
